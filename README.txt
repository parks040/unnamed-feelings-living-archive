How to open
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension (by Ritwick Dey) if you don't have it.
3. Right-click index.html > "Open with Live Server".

Use Live Server (or any local server). Double-clicking index.html will open the page,
but the ASCII section (08) will stay on "Loading drawings..." because browsers block
loading media/receipts.json from a plain file.

Fonts (Fraunces, Commissioner, IBM Plex Mono) load from Google Fonts, so stay online
for the presentation.

Folder
index.html          the whole site (HTML, CSS, JS in one file)
media/              videos, drawings, specimen spreads, glyph images, receipt previews
media/receipts.json ASCII drawings with sentences and dates (section 08)
